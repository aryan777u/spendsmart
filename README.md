# SpendSmart – Student Expense Tracker

> Know what you can spend today, not just what you spent.

SpendSmart helps students manage monthly expenses and savings. Enter your allowance and savings goal, log expenses by category, and see a safe daily spending limit that updates in real time.

Built for the **Roxten Studios – Build Your Own Website Hackathon**.

**Live site:** https://aryan777u.github.io/spendsmart/

## Features

- **Daily allowance:** income minus savings goal minus spending, spread over the days left in the month
- **Expense categories:** Food, Travel, Study, Fun, Shopping, Bills
- **Budget limits:** editable per-category limits with green, yellow and red progress bars
- **Charts:** donut chart (spending by category) and daily spending bar chart, drawn in plain SVG
- **Runway warning:** predicts whether your money lasts until month end at your current pace
- **Savings goal progress** bar
- **Month switcher**, delete expenses, **CSV export**
- Dark mode, responsive mobile layout, data saved in the browser (localStorage)

## Tech

HTML, CSS and vanilla JavaScript in a single `index.html`. No frameworks and no chart libraries.
Font: Bricolage Grotesque (Google Fonts).

## Run locally

Download `index.html` and open it in any browser.
